# 闸机与班报数据字典

## 文件、时间及编号

| 文件 | 字段 |
|---|---|
| `pulses.csv` | `pulse` 全批唯一触发编号，`station` 站点，`gate` 站内闸机，`beam` 外侧 A 或内侧 B，`device_at` 设备记录时刻，`ticket` 可空票号，`note` 可空采样说明 |
| `offsets.csv` | `station`、`gate`，`device_from` 与 `device_to` 是设备记录时间的左闭右开有效区间，`offset_ms` 为带符号整数，绝对值不超过 120,000 毫秒 |
| `passes.csv` | `ticket`，`valid_from` 与 `valid_to` 是标准时间的左闭右开有效区间，`transfer` 为 `yes` 或 `no` |
| `links.csv` | `from_station` 与 `to_station` 为有向异站键，`min_seconds` 与 `max_seconds` 为闭区间的相邻进出完成间隔，整数范围 1 至 3,600 秒 |

两通道各提供中断触发时刻。编号以英文或数字开头，最多 64 字节，可含连字符和下划线。票号按文本保留前导零。空串、`-`、`N/A`、`NULL`、`未知` 规范为空；只允许票号和备注可空。时刻接受 2000–2099 年内带时区的 ISO 时间，可带 1–3 位小数。内部用 UTC 纪元整数毫秒，页面显示上海时区。

CSV 接受 UTF-8、UTF-8 BOM、GB18030。列序可变，允许与初始表头同序的重复表头。逻辑记录保存物理起止行和原始字段。错误编码、表头、文件截断整批失败，记录错列、坏字段或业务冲突单行隔离。规范字段相同的重复记录保留最早来源，触发备注忽略；规范字段不同的相同键全组隔离。仅表头允许表示空规则表，至少一条业务上可采信且可校时的触发才能发布。

## 校时与配对

标准时刻以 `corrected_ms = device_ms − offset_ms` 计算。先在设备记录时间上找唯一的生效版本；缺失或重叠则保留偏移候选行并隔离该触发。完全相同的偏移版本去重。同一时窗的相互矛盾版本都参与阻断，防止选择更宽的第三个时窗盖掉冲突。

以 `(station, gate)` 独立排序。两束在同一校正毫秒触发时，等时帧全部进入一组歧义，并切断同闸机待配对窗口。在帧之间按相同票号分流，空票归匿名流且与有票流隔离。同束先进先出，遇另一束配给等待队首，要求 `0 < 间隔 ≤ 900 ms`。同束超过窗口或文件结束仍缺配对时按孤脉冲记录。

- 合格 `A→B` 算进站，`B→A` 算出站。完成时刻为末束时刻。
- 同一流连续出现 `A→B→A` 或 `B→A→B`，两段均在 `(0, 250 ms]`，且当时没有同束排队时，三束形成一个往返证据组。有票判折返，匿名判歧义。与尾随排队相交时保留原配对顺序。
- 等时帧不能从编号推定先后。孤脉冲不能仅凭单束推定是折返。三束规则是用于离线报表的保守判读，需要三束证据才归折返。

## 换乘与班次

只对有效进站尝试换乘。使用同票、票凭证允许换乘、进出完成时刻都在票凭证有效期内、非同站、有向通道存在且时距在闭区间内的最近未消费出站作为锚点。每个锚点至多消费一次。无票、不具资格或无法匹配的有效进站保留独立人次。进出物理量不扣换乘，换乘只扣入站的人次指标。

上海时区早班 `[06:00, 14:00)`、中班 `[14:00, 22:00)`、夜班 `[22:00, 次日06:00)`。夜班使用起班日期。每条脉冲按自身校正时间入班，配对判定按末束时刻入班。锚点出站班与后续进站班分别记换乘出、换乘进，跨午夜和班次也按时间窗计算。

- 可回放触发 = 配对证据脉冲（含折返和歧义）+ 孤脉冲 + 可校时的重复。无法校时的触发及重复另列。另逐脉冲 ID 核对，避免总数相等掩盖丢失与重复。
- 进站 = 去重进站 + 换乘进。物理净数 = 进站 − 出站；换乘净数 = 换乘进 − 换乘出；扣换乘净数 = 物理净数 − 换乘净数。全批换乘净数应为零。
- 各文件逻辑行 = 采信 + 隔离 + 表头 + 空行。核验失败时不发布。
- 凭证 ZIP 保留原始输入字节、逐脉冲与配对证据、换乘与班报 CSV、原因码及带成员 SHA-256 的清单。CSV 导入电子表格时把票号列指定为文本。

## 人工放行补偿账

闸机故障期间站务按人工计数分批放行，乘客仍可能刷卡或再次过闸。恢复后闸机记录与人工记数混进同一班次：全算会重复，只认刷卡则放行人数消失。补偿账按站、班次和放行方向单列一本账，不改写正式班报。

- 补录字段：`batch` 批次键（站内唯一，同键补录幂等）、`station`、`direction` 为 `entry`（进站放行）或 `exit`（出站放行）、`start` 与 `end` 为故障窗口的左闭右开标准时间、`released` 人工放行人数（1–999,999）、`entered_by` 录入人、`note` 可空备注。作废必须留原因，核对说明可空。
- 重复抵掉 = 同站同向且完成时刻落在故障窗口内的闸机有效进出数。净补偿 = 人工放行 − 重复抵掉。批次按窗口起点入班，窗口跨班次仅标记不阻断。
- 口径取舍：正式班报只含闸机核实数，未经核对的人工记数不改写班报；待核对净补在补偿账实时可见（交班侧影响可追溯），已核对净补以「发布口径 = 闸机已记 + 已核对净补」单列呈现，「全核口径」预览全部核对后的合计。
- 阻断发布的情形：同站同向故障窗口重叠（同一闸机记录会被两批抵掉）、重复抵掉超过放行人数、站点不在本批闸机记录中。窗口跨班次只是标记。
- 幂等与留痕：同键同内容补录复用原版本不重复累计；同键异内容升版，旧版标记被取代且核对不沿用；作废保留记录不计入补偿；重跑同源输入复用同一回放批次，补偿账不变。核对按版本生效，改版后需重新核对。
- 发布：勾稽通过才替换当前发布版，失败保留旧版并记录失败尝试及原因；原始提交报文、被取代版本、作废版本与发布历史全部保留，不丢失记录。样例预览只读。
